# audiovisual-softmae-lm

Reproducibility code for **"Audiovisual Language Models for Age Estimation and Minor Detection: A Comparative Study with Specialized Baselines"**. This repo covers data preparation, fine-tuning Gemma 4 E4B with the SoftMAE objective, and evaluation including minor detection metrics.

SoftMAE fine-tunes a multimodal LLM with a combined cross-entropy + soft-MAE objective. The soft-MAE term computes a closed softmax over 100 age-token logits, derives E[age], and penalises |E[age] − true_age| with L1 loss. At λ=0.9 this achieves **MAE 2.619 ± 0.223** on the boundary-val set (ages 14–21), versus 2.788 ± 0.306 for cross-entropy alone, and reduces minor-detection errors from 28.4 ± 2.2 to 24.6 ± 3.5 and the false-negative rate from 42.0 ± 4.9% to 30.0 ± 7.1%.

## Datasets

### UniformAge-AV (training set)

3000 training + 500 validation samples, ages 0–80. Built from two sources:

- **KAN-AV** — contact the authors to obtain the dataset (see citation below). **License prohibits redistribution**, so UniformAge-AV cannot be released.
- **IDIAPAge** — download from [Zenodo (record 7057376)](https://zenodo.org/records/7057376) (CC-BY-SA 4.0). Source videos come from YouTube; some segments may be unavailable.

### Boundary-500 (evaluation set — not redistributable)

500 KAN-AV clips from ages 14–21 (the adult/minor boundary). Built entirely from KAN-AV, so subject to the same redistribution restriction. All scripts to build this from raw KAN-AV are in this repo. Split into:
- **Boundary-Val** — 100 samples, stratified by age (used for early stopping during training)
- **Boundary-Test** — 400 samples, stratified by age (held-out test set)

## Data preparation

### KAN-AV

Both sample lists (`boundary_500_samples.json`, `balanced_1000_samples.json`) are generated by `create_kanav_sample_lists.py` from `sample_duration_list.json`, which is **provided with the raw KAN-AV dataset** under `Other/`.

```bash
KAN_ROOT=/path/to/KAN

# 1. Generate sample list JSONs from KAN-AV's own metadata
#    Outputs: $KAN_ROOT/boundary_500_samples.json
#             $KAN_ROOT/balanced_1000_samples.json
python data_prep/create_kanav_sample_lists.py --kan_root $KAN_ROOT

# 2a. Extract the training pool (Balanced-1000)
#     Samples at 1fps, saves first face-detected sample per clip
python data_prep/extract_kanav_dataset.py \
    --kan_root     $KAN_ROOT \
    --samples_json $KAN_ROOT/balanced_1000_samples.json \
    --output_dir   kanav_balanced_1000 \
    --output_csv   manifest.csv

# 2b. Extract the boundary evaluation set (Boundary-500)
#     Samples at 1fps, saves first face-detected sample per clip
python data_prep/extract_kanav_dataset.py \
    --kan_root     $KAN_ROOT \
    --samples_json $KAN_ROOT/boundary_500_samples.json \
    --output_dir   boundary_500_dataset \
    --output_csv   boundary_500.csv

# 3. Split Boundary-500 into Boundary-Val (100) and Boundary-Test (400), stratified by age
python data_prep/split_boundary_dataset.py \
    --boundary_csv boundary_500_dataset/boundary_500.csv \
    --output_dir   boundary_500_dataset
```

**KAN-AV directory structure** (after extracting the distributed tarballs):
```
KAN/
├── 01_silent_video/Batch{1-9}/{Person}/{AGE}/{clip}.avi
├── 02_audio_16k/Batch{1-9}/{Person}/{AGE}/{clip}.wav
└── Other/
    └── sample_duration_list.json   ← provided with dataset (28,003 entries)
```
Path format example: `Batch6/Natalie_Wood/14/14_000960_001041_000`
Age is the third path component (the video-id folder name).

### IDIAPAge

Download the dataset from [Zenodo record 7057376](https://zenodo.org/records/7057376). The Zenodo archive contains `train.csv`, `val.csv`, and `test.csv` with columns `clip, age, source, split`.

```bash
# 1. Download YouTube video segments
python data_prep/download_idiapage_segments.py \
    --splits train.csv val.csv test.csv \
    --output_dir video_segments

# 2. Extract 16kHz audio + uncropped frames at 1fps (RetinaFace detection, no cropping)
python data_prep/preprocess_idiapage.py \
    --video_dir   video_segments \
    --output_dir  idiapage_processed

# 3. Convert Zenodo split CSVs to formatted CSVs (picks first face-detected frame per clip)
python data_prep/format_idiapage_splits.py \
    --zenodo_csv train.csv --processed_dir idiapage_processed \
    --output_csv idiapage_processed/train_formatted.csv
python data_prep/format_idiapage_splits.py \
    --zenodo_csv val.csv   --processed_dir idiapage_processed \
    --output_csv idiapage_processed/validation_formatted.csv
python data_prep/format_idiapage_splits.py \
    --zenodo_csv test.csv  --processed_dir idiapage_processed \
    --output_csv idiapage_processed/test_formatted.csv
```

### Build UniformAge-AV

```bash
python data_prep/build_uniformage_dataset.py \
    --idiapage_dir  idiapage_processed \
    --kanav_dir     kanav_balanced_1000 \
    --boundary_csv  boundary_500_dataset/boundary_500.csv \
    --output_dir    uniformage_av
```

Expected output: `train_formatted.csv` (3000 samples), `validation_formatted.csv` (500). No test split is produced — the test sets are Boundary-Test (KAN-AV, ages 14–21) and Balanced-1000.

## Checkpoint

A trained LoRA adapter is included in `checkpoint/`. It corresponds to epoch 2 of training with `LAMBDA=0.9`, `SEED=7331`, achieving boundary-val MAE 2.268 (ages 14–21).

The base model (`unsloth/gemma-4-E4B-it`) is downloaded automatically by Unsloth from HuggingFace on first use — no manual download required.

To run evaluation directly with the included checkpoint:

```bash
python evaluate.py \
    --checkpoint checkpoint \
    --eval_csv   boundary_500_dataset/boundary_test.csv \
    --eval_dir   boundary_500_dataset \
    --output     results/checkpoint_boundary_test.csv
```

## Training

```bash
LAMBDA=0.9 SEED=7331 python train.py \
    --dataset_dir      uniformage_av \
    --boundary_val_csv boundary_500_dataset/boundary_val.csv \
    --boundary_val_dir boundary_500_dataset \
    --output_dir       output/lambda09_s7331
```

Key environment variables:

| Variable | Default | Description |
|----------|---------|-------------|
| `LAMBDA` | `0.9` | Weight of soft-MAE loss term (λ in paper) |
| `NUM_EPOCHS` | `5` | Training epochs. Cosine LR schedule spans the full epoch count — changing this reshapes the schedule, not just the stopping point. Early stopping may fire before the ceiling. |
| `SEED` | `3407` | Random seed |
| `LEARNING_RATE` | `2e-4` | AdamW learning rate |
| `LORA_R` | `16` | LoRA rank |
| `LORA_ALPHA` | `32` | LoRA alpha |

Batch size is fixed at 1 with gradient accumulation of 8 (effective batch size 8). A single A5000 (24 GB) with full audio-visual inputs at `max_seq_length=8192` cannot fit larger batches. `NUM_EPOCHS=5` is both the ceiling and the value used in all reported runs; the cosine LR schedule is computed over the full 5 epochs so early stopping (patience=3, min_epochs=3, min_delta=1%) fires within the correctly-shaped schedule.

## How SoftMAE works

Standard cross-entropy treats age prediction as 100-class classification with no ordinal structure. SoftMAE adds an auxiliary loss:

```
soft_age = Σ_a softmax(logit_a) · a        # expected age under model distribution
mae_loss = |soft_age − true_age|            # L1 penalty
total    = CE_loss + λ · mae_loss
```

The softmax is closed over the 100 age tokens (0–99), so the model learns ordinal representations without any reweighting or digit decomposition.
